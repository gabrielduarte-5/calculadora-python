# Calculadora em Python

## Sobre o projeto
Criei esta calculadora como parte dos meus estudos de lógica de programação em Python, durante minha graduação em Engenharia de Software.

O objetivo foi praticar operações matemáticas, entrada de dados e estruturas condicionais, desenvolvendo um programa simples e funcional.

## Funcionalidades
- Realizar operações de adição.
- Realizar operações de subtração.
- Realizar operações de multiplicação.
- Realizar operações de divisão.
- Selecionar a operação desejada.

## Conhecimentos utilizados
Python, variáveis, operadores matemáticos, entrada de dados com `input()` e estruturas condicionais (`if`, `elif`, `else`).

## Como executar
Execute o arquivo Python do projeto em um ambiente com Python 3 instalado.

**Observação:** Projeto desenvolvido para praticar conceitos fundamentais de programação.
